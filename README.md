# StockChat

AI-powered livestock management system that enables natural conversations about animal health and monitoring.

## Features
- 🤖 Natural language conversations
- 📊 Real-time sensor monitoring
- 🚨 Automated abnormality detection
- 📝 Document processing
- 💡 Intelligent alerts

## Demo
Check out the live demo: [StockChat on Streamlit](https://stockchat.streamlit.app)

## Local Development
```bash
# Clone the repository
git clone https://github.com/chokethenetwork/StockChat.git

# Install dependencies
pip install -r requirements.txt

# Run the app
streamlit run src/app.py
```

## Environment Variables
Create a `.env` file with:
```
HUGGINGFACE_API_KEY=your_key_here
```
